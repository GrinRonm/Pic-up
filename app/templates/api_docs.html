REST API Reference • v2.0

Документация API Pic-up

Простой, быстрый и надёжный HTTP API для программной загрузки и получения файлов.
Без ключей API, без токенов, без регистрации.

Интерактивный Swagger UI ReDoc Спецификация
Базовый адрес API (Base URL) HTTPS Only • CORS Enabled
{{ app_url }}/api
POST
/api/upload Загрузка файлов

Загружает один или несколько файлов любого формата (изображения, видео, аудио, архивы, документы, программы). Файлы сохраняются в защищённом хранилище Telegram и выдаются готовые ссылки.

Параметры запроса (Content-Type: multipart/form-data)

Параметр Тип Обязательный Описание
files или file binary[] Да Один или несколько файлов. Максимум {{ max_files }} файлов за один запрос, до {{ max_size_mb }} МБ каждый.

Примеры кода

# Загрузка одного файла
curl -X POST "{{ app_url }}/api/upload" \
  -F "file=@photo.jpg"

# Загрузка нескольких файлов сразу
curl -X POST "{{ app_url }}/api/upload" \
  -F "files=@video.mp4" \
  -F "files=@archive.zip"
import requests

url = "{{ app_url }}/api/upload"

# Загрузка одного или нескольких файлов
with open("my_video.mp4", "rb") as f:
    files = [
        ("files", ("my_video.mp4", f, "video/mp4")),
    ]
    response = requests.post(url, files=files)
    data = response.json()

print("Код подборки:", data["batch_code"])
print("Ссылка на просмотр:", data["view_url"])
for item in data["files"]:
    print("Файл:", item["original_name"], "->", item["url"])
const formData = new FormData();
formData.append('files', fileInput.files[0]);

const response = await fetch('{{ app_url }}/api/upload', {
    method: 'POST',
    body: formData
});

const data = await response.json();
console.log('Подборка:', data.view_url);
console.log('Файлы:', data.files);
<?php
$ch = curl_init('{{ app_url }}/api/upload');
curl_setopt($ch, CURLOPT_POST, true);
curl_setopt($ch, CURLOPT_POSTFIELDS, [
    'files[0]' => new CURLFile('/path/to/archive.zip')
]);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
$result = json_decode(curl_exec($ch), true);
curl_close($ch);

echo "Ссылка на подборку: " . $result['view_url'];
?>

GET
/api/batch/{code} Метаданные подборки

Возвращает метаданные подборки, дату истечения срока, статус отправки файлов в Telegram, количество и размер каждого файла. 

curl -s "{{ app_url }}/api/batch/b69e663586f2e551"
GET
/i/{filename} Потоковый просмотр

Прямая отдача файла с поддержкой заголовка Range (HTTP 206 Partial Content). Необходим для воспроизведения и мгновенной перемотки видео и аудио в плеерах браузеров и на iOS/Android.

GET
/download/file/{filename} Прямое скачивание

Скачивает конкретный файл с принудительным заголовком Content-Disposition: attachment и оригинальным именем файла.

GET
/download/{code} ZIP Архив подборки

Динамически упаковывает все файлы подборки в единый ZIP-архив и отдаёт его клиенту.
