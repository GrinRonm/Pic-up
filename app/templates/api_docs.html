REST API v2.0

Документация публичного API Pic-up

Публичный API для моментальной загрузки и обмена любыми файлами.
Без ключей API, без токенов, без регистрации.

Интерактивный Swagger UI ↗ ReDoc ↗

Базовый URL

{{ app_url }}/api
POST /api/upload

Загрузка одного или нескольких файлов (фото, видео, музыка, документы, архивы). Возвращает ссылки на просмотр, скачивание и QR-код.

Параметры запроса (multipart/form-data)

Поле Тип Обязательное Описание
files или file File / Binary Да Один или несколько файлов (до {{ max_files }} файлов, до {{ max_size_mb }} МБ каждый).

Примеры запросов

# Загрузка одного файла
curl -X POST "{{ app_url }}/api/upload" \
  -F "file=@photo.jpg"

# Загрузка нескольких файлов
curl -X POST "{{ app_url }}/api/upload" \
  -F "files=@video.mp4" \
  -F "files=@document.pdf"
import requests

url = "{{ app_url }}/api/upload"

# Загрузка файла
with open("my_video.mp4", "rb") as f:
    files = {"files": ("my_video.mp4", f, "video/mp4")}
    response = requests.post(url, files=files)

data = response.json()
print("Ссылка на подборку:", data["view_url"])
for item in data["files"]:
    print("Прямая ссылка:", item["url"])
const formData = new FormData();
formData.append('files', fileInput.files[0]);

fetch('{{ app_url }}/api/upload', {
  method: 'POST',
  body: formData
})
.then(res => res.json())
.then(data => {
  console.log('Ссылка:', data.view_url);
  console.log('Файлы:', data.files);
});
<?php
$ch = curl_init('{{ app_url }}/api/upload');
curl_setopt($ch, CURLOPT_POST, true);
curl_setopt($ch, CURLOPT_POSTFIELDS, [
    'files[0]' => new CURLFile('/path/to/archive.zip')
]);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
$response = curl_exec($ch);
curl_close($ch);

$result = json_decode($response, true);
echo "Ссылка: " . $result['view_url'];
?>

GET /api/batch/{code}

Получение информации о подборке и списка файлов в JSON формате.

curl "{{ app_url }}/api/batch/4121a911828f99b6"
GET /i/{filename}

Прямой просмотр и потоковое воспроизведение файла. Поддерживает заголовок Range (HTTP 206) для перемотки видео и аудио в любых браузерах.

curl -I "{{ app_url }}/i/7499c60fadf544ec.mp4"
GET /download/file/{filename}

Прямое скачивание конкретного файла с заголовком Content-Disposition: attachment с оригинальным именем.

GET /download/{code}

Скачивание всех файлов подборки одним ZIP архивом.
